# ICP-to-Content Mapping

## Purpose
Maps each ICP segment to the content they are most likely to search for and find valuable. Used for:
- Prioritising the Content Pipeline
- Ensuring content briefs are targeted correctly
- Identifying content gaps by segment

**This file is the catalogue view** — it answers "what content does each segment need and at what priority?" For the pain-point-driven view (which specific anxiety each piece addresses, used as brief-writing input), see `icp-pain-point-content-matrix.md`.

**Sync rule:** When a content title changes in either file, it must be updated in both. These two files are the canonical references for content titles across the system.

**url-slug column:** matches a slug in the [Canonical URL Inventory](../sitemap/canonical-url-inventory.md). A value of `pending` means the piece has no current inventory slot — review whether to add it or merge it into an existing page.
