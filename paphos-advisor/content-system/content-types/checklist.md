# Content Type: Checklist

## Definition
An actionable, task-oriented document that helps a client complete a process or prepare for a move. Optimised for practical use — printable, scannable, and sequenced correctly.

## Variants

This file defines the rules for **general checklists** — pre-move checklists, document preparation checklists, and other non-process-linked checklist content.

For checklists tied to a specific PROC-XXX process document, the additional and overriding rules are in [`process-checklist.md`](process-checklist.md). All rules in this file also apply to process-linked checklists unless overridden there.

## Word count
500–1,200 words

## Required sections

1. **Purpose statement** (1 paragraph) — what this checklist covers and who it is for
2. **Before you start** — prerequisites (things you need to know or have before using this checklist)
3. **Checklist phases** — grouped by logical phase or timing (Before Arrival / Week 1 / Month 1–3, etc.)
4. **Documents Required** — table format (Document | Format | Where to get it)
5. **Timeline summary** — estimated time for each phase
6. **Notes section** — blank space for personalisation (in PDF version)
7. **Disclaimer** — standard accuracy disclaimer

## Checklist item format

```
☐ [Action verb] [specific task] — [optional: where/when/how long]
```

Examples:
✓ `☐ Book MEU1 appointment at CRMD Paphos — book 2-4 weeks before you need it`
✓ `☐ Get rental agreement stamped by the Tax Department — before your CRMD appointment`
✗ `☐ Yellow Slip` (not a task, just a noun)
✗ `☐ Make sure you have all your documents ready` (too vague)

## Phase structure examples

**Pre-Arrival Checklist phases:**
1. 3 months before — Research and planning
2. 1 month before — Document preparation
3. Week before — Final checks

*Process-linked checklists use a different phase structure — see [`process-checklist.md`](process-checklist.md).*

## PDF version requirements

All checklists must be available as a downloadable PDF:
- A4 format
- Includes version date and "last updated" notice
- Includes accuracy disclaimer
- Includes Paphos Advisors branding
- Naming convention: `[process-slug]-checklist-[YYYY-MM].pdf`
