# Internal Linking Rules

## Purpose
Defines how internal links are used across the content system to reinforce topical structure, distribute authority, and help users navigate.

---

## Core Rules

**1. Minimum density:** 2 internal links per 1,000 words.

**2. Anchor text:** Always descriptive. Never "click here", "read more", or "this page".
✓ `...see our guide to [getting a Yellow Slip in Cyprus]`
✗ `...for more information, [click here]`

**3. Link to the most specific relevant page.** Don't link to a pillar page when a cluster page answers the question better.

**4. No broken links.** Never link to a page that does not exist yet. If the page is planned but not live, mention it in text without a link.

**5. One link per target per page.** Do not link to the same destination page more than once in the same article. The first occurrence is the link; subsequent mentions are plain text.

---

## Pillar-Cluster Linking Structure

**Cluster pages must link to their pillar page.** Every cluster piece must include at least one link back to the parent pillar page.

**Pillar pages must link to their cluster pages.** The pillar page is the hub. It links outward to all related cluster pieces.

**Cluster pages should link laterally to related clusters.** If a Yellow Slip guide mentions tax residency, link to the 60-Day Rule page.

---

## Anti-Cannibalisation Rules

Do not create two pieces of content that target the same keyword or answer the same question. Before creating a new piece:

1. Search the content library for existing pieces on the topic
2. Check the topical map for planned coverage
3. If overlap exists, consolidate rather than duplicate

If a topic needs both a high-level overview and a detailed guide:
- The overview is part of the pillar page
- The detailed guide is a separate cluster page
- They serve different intent and keyword targets — do not overlap the body content

---

## Link Placement

**In-text links:** Natural occurrence within a sentence. Most valuable for SEO.

**Related content links:** A "Related guides" or "You might also find useful" section at the end of the page. These are supplementary, not a substitute for in-text links.

**CTA links:** "Get help with your Yellow Slip application" — link to contact/enquiry page. One per page, near the end or in a callout box. Not in the middle of informational content.

---

## External Links

- Link to official government sources where relevant (opens in new tab)
- Do not link to competitor websites
- Do not link to sources you have not reviewed for accuracy
- External links should be `rel="noopener"` for security

---

## Review

When a page is significantly updated, check that all internal links pointing to it still work and that anchor text still matches the updated content. Use Google Search Console to monitor for 404s.
